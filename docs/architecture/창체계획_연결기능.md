# 창의적 체험활동 계획 연결 (만들어 뒀지만 화면에는 없음)

- 상태: **구현 완료 · UI 미노출** (2026-08-20)
- 숨긴 이유: 시간표 탭의 순서를 단순하게 하려고. 기능은 그대로 살아 있다.
- 다시 꺼내려면: `MainWindow.xaml` 의 ① 단계에 단추 하나만 붙이면 된다 (아래 참고).

---

## 무엇을 하는 기능인가

연간 시간표에는 창의적 체험활동이 **`창`** 처럼 종류 없이 적히는 경우가 있다.
나이스는 자율·자치활동 / 동아리활동 / 진로활동을 **따로** 받으므로,
`창` 만으로는 어느 것을 넣을지 알 수 없다 → 그 칸은 실행이 막힌다.

**창체 계획서**(주별 활동 계획)를 함께 넣으면 그 날의 활동으로 종류를 정해 준다.

```
시간표:  9/2 5교시  "창"          ← 종류 모름
창체계획: 9/2  자율활동 (우쿠렐레)  ← 종류 있음
                ↓
시간표:  9/2 5교시  "자"          ← 자율·자치활동으로 확정
```

## 어디에 무엇이 있나

| 파일 | 하는 일 |
|---|---|
| `Core/Timetable/CreativeDocumentParser.cs` | 창체 계획 문서(표)를 읽는다. 머리글 `주\|날짜\|요일\|학습주제\|활동내용\|차시\|영역\|비고` |
| `Core/Timetable/CreativeActivityMerger.cs` | **창체 전체**와 **영역별** 계획이 겹치는 것을 한 건으로 합친다 |
| `Core/Timetable/CreativeActivityLinker.cs` | 시간표의 창체 칸과 계획을 잇는다. 학년도·학기·기간이 어긋나면 알린다 |
| `App/ViewModels/TimetableTabViewModel.cs` | `LoadCreativeCommand` · `ApplyCreativeLinks()` — 파일을 고르고 칸에 반영한다 |

## 이어 붙이는 규칙 (기술설계 §8)

- 원본에 종류가 적혀 있으면(`자`·`동`·`진`) **그대로 쓴다** — 가장 확실한 근거다
- 미분류(`창`·`봉`)는 그 날 계획에서 종류를 가져온다
- 그 날 계획이 **여러 종류면 충돌로 둔다.** 계획에는 교시가 없어 어느 칸이 무엇인지 알 수 없다 (D-008)
- 원본과 계획이 어긋나도 충돌 — 조용히 한쪽을 택하지 않는다

## 겹치는 계획을 한 건으로 (사용자 요구)

창체 계획서에는 같은 활동이 **"창체 전체"** 와 **"영역별"** 로 두 번 나오는 일이 흔하다.
이 둘을 별개로 세면 시수가 두 배가 된다 → `CreativeActivityMerger` 가 한 건으로 합친다.

- 완전히 같으면 합치고, 설명은 더 자세한 쪽을 남긴다
- 차시만 다르면 합치되 사용자에게 제안으로 보여 준다
- 종류나 교시가 어긋나면 **충돌**로 두고 사람이 정한다

## 화면에 다시 꺼내려면

① 단계(`MainWindow.xaml`, `시간표 문서` 카드) 안에 단추 하나:

```xml
<Button Style="{StaticResource GhostButton}" Content="📄 창의적 체험활동 (선택)"
        Command="{Binding LoadCreativeCommand}" HorizontalAlignment="Stretch"
        HorizontalContentAlignment="Left" Padding="10,6" Margin="0,6,0,0" FontSize="12"
        ToolTip="넣으면 '창' 칸의 종류(자율·동아리·진로)를 정해 줍니다"/>
<TextBlock Text="{Binding CreativeFileName}" Style="{StaticResource StepNote}"/>
```

VM 쪽은 손댈 것이 없다 — `LoadCreativeCommand` 와 `CreativeFileName` 이 그대로 있다.

## 실측으로 확인된 것

- 예시 창체 파일(`docs/schedule/창체.pdf`)은 **2026학년도**, 시간표는 **2025학년도** 라
  짝이 맞지 않는다. 프로그램이 이것을 잡아낸다:
  `"학년도가 다릅니다 — 시간표 2025, 창체 2026"`, `"창체 일정이 모두 시간표 기간 밖입니다"`
- 그래서 **계획서 덕에 종류가 정해지는 것은 아직 실측으로 확인하지 못했다.**
  6학년 문서에서 해결된 98칸은 전부 원본에 이미 `자·동·진` 이 적혀 있던 것이다.
  → **같은 학년도 짝**이 있어야 이 기능을 검증할 수 있다.
- 계획서 파싱 자체는 된다: 52건 → 병합 46건 · 충돌 1건
- 알려진 흠: 활동명이 잘리는 경우가 있다 ("학급 다모임" → "급모임")
