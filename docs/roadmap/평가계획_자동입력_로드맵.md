## 0. 원칙

연간 시간표에서 지킨 것을 그대로 가져온다.

1. **한 번에 하나씩.** 각 단계가 끝나면 사용자가 눈으로 확인할 결과가 나온다.
2. **읽기가 먼저.** 쓰기는 읽기·계획이 다 맞은 뒤에만.
3. **클릭 성공은 입력 성공이 아니다.** 넣은 뒤 다시 읽어 대조한다.
4. **되돌릴 수 없는 것은 사람이.** 삭제는 자동화하지 않는다.
5. 막힌 것이 하나라도 있으면 **실행을 잠근다.**

## 5. 진행 기록

### 2026-08-21 · E5·E6·E7 실제 입력 · ✅ — 2학기 국어 전 과정 통과

문서에서 읽은 것을 <b>나이스에 실제로 넣고 저장하고 재조회로 확인</b>했다.

```
① 영역명 등록   문학 / 쓰기 / 매체
② 성취기준      3건 입력·저장
③ 평가기준      3건 × 3단계 입력·저장
재조회          평가요소 ✅ · 평가기준 3단계 ✅ (3건 모두)   일치 3 · 어긋남 0
```

만든 것: `EvalPlanWriter` (`RegisterAreasAsync` · `AddStandardsAsync` · `WriteCriteriaAsync` · `SaveAsync`)

**막힌 네 곳 — 전부 "칸을 어떻게 확정하나" 였다**

| 증상 | 원인 | 고침 |
|---|---|---|
| `영역명은 공백으로 입력할 수 없습니다` | 한 줄 칸(`INPUT`)은 <b>Enter 로 확정</b>되는데 연쇄로 채워 마지막이 비었다 | 편집기가 `INPUT` 이면 Enter, `TEXTAREA` 면 연쇄 |
| 행을 더해도 늘지 않음 | 상자 뒤 <b>본문 그리드</b>를 잡고 있었다 (둘 다 "영역명" 열을 갖는다) | 상자가 열려 있으면 <b>그 안을 먼저</b> 찾는다 |
| `목록에서 '쓰기' 를 찾지 못했습니다` | 앞 칸 확정용 클릭이 <b>이미 콤보를 열어</b> 놨는데 또 눌러 닫았다 | 열려 있으면 누르지 않는다 |
| 열 번호가 안 맞음 | 같은 값의 열이 화면마다 자리가 다르다 (영역명 2열 ↔ 1열) | <b>머리글로 찾는다</b> — 문서 파서와 같은 교훈 |

- 실패·제약: 중간에 실패해 남은 빈 행이 다음 저장을 막는다. <b>조회를 누르면 버려진다</b> — 실행 전에 한 번 조회하는 것으로 충분하다
- 실기기에 남긴 것: 2026학년도 2학기 5학년 <b>국어</b>에 문학·쓰기·매체 3건이 <b>진짜로 들어가 있다</b>. 문서 그대로다
- 다음 작업: E8 엑셀 일괄업로드 → E9 평가 탭 UI


### 2026-08-21 · E1 다듬기 — 원문 대조로 검증 · ✅

사용자 물음: <b>"온전한지 내가 어떻게 확인하지"</b> — 옳은 지적이었다.
원본과 90건을 손으로 맞춰 보라는 건 <b>내 일을 떠넘긴 것</b>이었다.

**기계로 대조하는 방법을 만들었다.** 파서가 좌표로 재조립한 문장이
<b>PDF 원문 글자 흐름 안에 그대로 들어 있는지</b> 맞춰 본다. 글자가 빠지거나 순서가 뒤바뀌면 걸린다.
띄어쓰기를 뺀 것과 넣은 것으로 두 번 본다.

그 대조가 <b>진짜 결함 셋</b>을 짚어 냈다.

| 결함 | 원인 | 고침 |
|---|---|---|
| `실기평가` → `실·기평가`, `듣기·말하기` → `듣·기말하기` | 가운뎃점이 폭 0.8pt 에 기준선이 3.8pt 떠 있어 윗줄로 끌려감 | 작은 기호를 <b>가장 가까운 글자 줄</b>에 붙인다 |
| 학교자율시간 쪽이 통째로 버려짐 | 머리글에 <b>성취기준 열이 없다</b> (`시기│평가 영역│평가 요소│평가 방법│평가 기준`) | 그런 표는 <b>영역</b>을 묶음 기준으로 |
| 성취기준이 쓰이다 말고 끊김 | 표 한 줄이 <b>쪽 경계에서 잘려</b> 나머지가 다음 쪽으로 넘어감. 그 쪽엔 머리글이 없다 | 열 경계가 같고 머리글이 없으면 <b>이어지는 표</b>로 보고 붙인다 |

마지막 것은 사용자가 검토 페이지에서 찾아 줬다 — <b>내 대조로는 못 잡는 것</b>이었다.
잘린 문장도 원문의 부분 문자열이라 "일치"로 나온다. <b>대조가 만능이 아니라는 것</b>을 배웠다.

**검산 (원문 대조 449조각)**

|---|---|---|---|---|
| 이지에듀 1학기 | 147 | 0 | 5 | 35 |
| 이지에듀 2학기 | 127 | 0 | 0 | 29 |
| 스쿨마스터 | 168 | 2 | 0 | 30 → <b>34</b> |

- 어긋난 5건은 전부 <b>쪽 꼬리말</b>("2026학년도 … 전주덕일초등학교")이 표에 섞인 것 — 버리면 된다
- 쪽 넘김 2건은 이어붙인 문장이라 원문 한 쪽 안에 통째로 없다. <b>기계로는 못 맞추니 표시해서 내보낸다</b>
- 스쿨마스터는 이어짐 처리로 <b>버려지던 성취기준 4건을 되찾았다</b>

- 검토 페이지: 사용자가 훑어보도록 따로 만들어 전달했다

**막힌 지점과 푼 방법**

| 막힌 것 | 푼 방법 |
|---|---|
| 글자 사이 빈틈으로 열을 못 나눔 (한 쪽에 4pt 이상 빈 구간이 <b>두 군데뿐</b>) | <b>표의 선</b>을 읽는다. 세로선 9개 = 8열, 가로선 91개 = 행 |
| 세로 병합된 칸(영역·성취기준)을 어떻게 아나 | <b>가로줄이 지나가지 않는 곳</b>이 병합이다. 그것으로 성취기준 묶음을 나눈다 |
| 띄어쓰기가 사라짐 | 추출기가 <b>공백 글자를 버리고 있었다</b>(한 쪽에 236개). 간격으로 추정해 봤더니 양쪽 정렬 때문에 <c>시 간</c>, <c>경 험</c> 으로 갈라졌다 — 원본 공백을 쓰는 게 답이었다 |
| `[6국04-05]` 가 `4 -[ 6 국 0 0 5 ]` 로 흩어짐 | 같은 줄인데 글자마다 기준선이 <b>3.7pt</b> 달랐다. 줄 묶음 오차를 2.5 → 4.5pt |
| 낱말 경계에서 줄이 바뀌면 공백이 사라짐 | 줄 끝 공백을 `Trim()` 하지 않고 이어 붙인다 |
| 양식마다 열이 다름 | <b>머리글을 읽어</b> 열을 찾는다. 열 번호를 못 박지 않는다 |
