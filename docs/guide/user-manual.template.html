시간표 7/7

1주 결과가 맞으면 날짜 범위를 다음 몇 주로 넓힙니다.
덮어쓰기가 필요하지 않다면 계속 꺼 둡니다.
실행하고 결과창에서 실패·미도달 주를 확인합니다.
원인을 고친 뒤 결과창의 재시도 또는 짧은 날짜 범위로 다시 실행합니다.
완료 확인전체 기간을 나이스에서 주차별로 확인했고, 실패·미도달 주가 남아 있지 않습니다.
