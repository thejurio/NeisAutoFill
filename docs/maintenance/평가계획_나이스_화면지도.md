# 평가계획 — 나이스 화면 지도 (실측)

최초 실측: 2026-08-21 · 전주덕일초 2026학년도 2학기 5학년 국어
관련: [기술설계](../architecture/평가계획_자동입력_기술설계.md) · [로드맵](../roadmap/평가계획_자동입력_로드맵.md)

이 문서는 **직접 한 건을 끝까지 만들어 저장하며 확인한 것만** 적는다. 추측은 "미확인"으로 표시한다.

---

## 1. 가는 길

```
학급담임 → 평가계획 → 평가계획(안)관리
```

한 화면 안에 **두 단계**가 카드로 나란히 있다. 카드를 누르면 아래 내용이 통째로 바뀐다.

```
┌─────────────────┐   ┌──────────────────────────┐
│   성취기준관리    │ ▶ │  성취기준(평가기준)관리   │
└─────────────────┘   └──────────────────────────┘
        1단계                     2단계
   영역·성취기준·평가요소      단계별 평가기준
```

## 2. 조회 조건

모두 `div[role=combobox][aria-label]` 이고, 목록 항목은 `div.cl-combobox-item[role=option]` 이다.

| aria-label | 값 | 비고 |
|---|---|---|
| `학년, 2026` | 학년<b>도</b> | 이름이 "학년"이라 아래 학년과 헷갈린다 — <b>순서로 구분</b> |
| `학기, 2` | 학기 | 1 / 2 |
| `학년, 5` | 학년 | |
| `교과, 국어` | 교과(목) | <b>일괄업로드는 이 교과 하나에만 적용된다</b> |
| `영역명, -전체-` | 영역 | |
| `단계선택, 3단계` | 단계 수 | 2단계에서만 |

조회 전에는 편집 단추가 **전부 꺼져 있다.** 반드시 [조회]를 먼저 누른다.

## 3. 1단계 — 성취기준관리

그리드 열: `영역순번 | 영역명 | 성취기준 | 평가요소 | 교과평가 | 관찰내용 | 정렬순서 | 등록사용자`

단추: `특수문자` `학년별평가관리기준` `일괄업로드` `영역명관리` `행추가` `가져오기` `저장` `삭제` `출력`

### 영역명은 미리 등록해야 한다 ★

영역명 칸은 <b>자유 입력이 아니라 콤보</b>다. [영역명관리]에 등록된 것만 고를 수 있다.

- **영역명관리** 대화상자 — 범위가 제목에 박혀 있다("2026학년도 2학기 5학년 국어")
- 그리드 `순번 | 영역명`, 단추 `특수문자` `행추가` `저장` `삭제` `닫기`
- 여기서 저장한 뒤라야 성취기준 행에서 그 영역을 고를 수 있다

> 이 순서를 지키지 않으면 성취기준을 넣을 방법이 아예 없다. **자동화의 첫 단계다.**

### 일괄업로드 (엑셀)

교과 하나 단위다(제목에 "5학년 국어").

- 단추: `샘플엑셀다운로드` `엑셀업로드` `일괄저장` `닫기`
- 그리드: `순번 | 영역명 | 성취기준 | 평가요소`
- 안내: <b>"기 등록된 영역명, 성취기준은 그대로 유지되고, 업로드한 성취기준이 추가로 등록됩니다."</b>
  → 덮어쓰기가 아니라 <b>추가</b>다. 두 번 올리면 두 벌이 생긴다.

#### 양식 (2026-08-22 확정)

사용자가 받아 준 샘플 파일을 뜯어 확정했다:

| | |
|---|---|
| 시트 이름 | <c>empty0</c> (<b>이름이 다르면 못 읽는다</b>) |
| 1행 | `영역명 │ 성취기준 │ 평가요소` — <b>셋뿐</b>이다. 넷째 칸은 없다 |
| 2행 | 빈 데이터 행(서식만) |

→ <b>샘플을 받을 필요가 없다.</b> 이 모양대로 만들어 올린다(`EvalUploadWorkbook`).

#### 영역명도 만들어 준다 ★ (2026-08-22 실측)

문서에는 "기 등록된 영역명…은 그대로 유지되고" 라고만 적혀 있어 <b>새 영역명을 만들어 주는지 몰랐다.</b>
<b>영역이 하나도 없던 도덕으로 올려 보니 영역명까지 생겼다.</b>

→ 그러므로 <b>[영역명관리]를 따로 부를 필요가 없다.</b> 일괄업로드 한 번이면 영역·성취기준·평가요소가 함께 들어간다.

#### 파일 선택 창은 가로채야 한다 ★

<b>대화상자 안에 <c>input[type=file]</c> 이 없다.</b> [엑셀업로드]를 누르면 그때 만들어진다.
Playwright 의 <c>RunAndWaitForFileChooserAsync</c> <b>안에서</b> 눌러야 가로채진다 —
그냥 누르면 OS 파일 창이 떠서 자동화가 통째로 멈춘다.

#### 저장 단추 이름이 다르다

이 창의 저장은 <c>저장</c> 이 아니라 <b><c>일괄저장</c></b> 이다.

## 4. 2단계 — 성취기준(평가기준)관리

- 왼쪽 그리드 `영역명 | 성취기준 | 평가요소` — 1단계에서 저장한 것이 나온다
- **왼쪽에서 행을 고르면** 오른쪽이 살아난다
- `단계선택` 콤보: `단계선택 / 2단계 / 3단계 / 4단계 / 5단계 / 7단계`
- 고르는 순간 오른쪽 그리드에 <b>그 수만큼 빈 행</b>이 생긴다
- 오른쪽 그리드 `평가단계 | 평가결과`
- 단추: `일괄입력`(행 고르기 전에는 꺼짐) `전과목일괄입력` `출력` `특수문자` `저장` `삭제`

### 전과목일괄입력은 파괴적이다 ⚠

대화상자에 붉은 글씨로 적혀 있다:

```
1. 기존에 입력되어 있던 평가기준이 삭제됩니다.
2. 해당 학년도, 학기, 학년에 개설된 교과의 모든 영역의 평가기준을 일괄입력합니다.
```

모든 교과·모든 영역에 <b>같은</b> 평가기준을 밀어 넣는 기능이다.
영역마다 평가결과가 다른 우리 용도에는 <b>쓰지 않는다.</b>

### 단계를 바꾸면 교과가 되돌아간다 ★★ (2026-08-22 실측)

<b>카드로 단계를 옮기면 조회 조건의 교과가 첫 항목(국어)으로 되돌아간다.</b>

이걸 몰라서, 도덕 성취기준을 넣고 2단계로 옮긴 뒤 <b>국어 화면에서 도덕 성취기준을 찾다</b>
"넣은 성취기준을 화면에서 찾지 못했습니다" 로 멈췄다.

→ <b>단계마다·교과마다 교과를 다시 고르고 [조회]한 뒤, 화면 표시값까지 대조</b>하고 넣는다.
→ 그래서 <b>단계 하나에서 전 교과를 돌고 다음 단계로</b> 가는 편이 낫다(전환이 2번으로 줄고, 실패 위치도 분명해진다).

## 5. 그리드 편집 규칙 ★★ (가장 값진 실측)

이 화면의 그리드는 **확정 규칙이 특이하다.** 모르면 입력이 조용히 사라진다.

| 하는 일 | 방법 |
|---|---|
| 텍스트 칸 편집 | <b>더블클릭</b> → `TEXTAREA.cl-text` 활성 → `Ctrl+A` → 텍스트 삽입 |
| 콤보 칸(영역명) 편집 | <b>한 번 클릭</b>하면 목록이 열린다 → 항목 클릭 |
| 편집 확정 | <b>다른 칸을 누른다</b> |

그리고 함정이 둘 있다.

1. **Enter·Tab·Escape 로는 확정되지 않는다.** Enter 는 줄바꿈, Escape 는 취소다.
   그리드 <b>바깥</b>을 눌러도 확정되지 않는다 — 편집이 그냥 버려진다.
2. **확정하려고 누른 그 칸이 비워진다.** 편집기가 하나뿐이라 자리를 옮기며 새로 열리는 탓으로 보인다.

그래서 이렇게 채운다:

```
(0,단계) 입력 → (0,결과) 클릭   ← (0,결과) 가 비워짐. 어차피 다음에 채운다
(0,결과) 입력 → (1,단계) 클릭
(1,단계) 입력 → (1,결과) 클릭
        ⋮
(2,결과) 입력 → [저장] 클릭      ← 저장이 편집 중인 칸을 확정한다
```

<b>다음에 채울 칸을 눌러 가며 연쇄로</b> 채우고, 마지막은 [저장]이 마무리한다.
실측에서 이 방식으로 3행 6칸이 한 번에 들어갔다.

> 그리드를 <b>처음 건드릴 때 한 번은</b> 편집모드 진입이 실패했다.
> 넣은 뒤에는 반드시 값을 다시 읽어 확인한다 — 시간표에서 지킨 원칙 그대로다.

### 칸 종류마다 확정 방법이 다르다 ★

| 칸 | 편집기 | 확정 |
|---|---|---|
| 영역명(상자), 정렬순서 | `INPUT` | <b>Enter</b> 로 확정된다 |
| 성취기준·평가요소·평가결과 | `TEXTAREA` | Enter 는 <b>줄바꿈</b>. 다음 칸을 눌러야 한다 |
| 영역명(본문) | 콤보 | 한 번 누르면 목록이 뜬다 → 항목 클릭이 곧 확정 |

한 줄 칸을 연쇄로 채웠더니 마지막 줄이 빈 채로 남아
나이스가 <c>영역명은 공백으로 입력할 수 없습니다</c> 로 저장을 거절했다(실측 2026-08-21).

> <b>콤보 칸 함정</b>: 앞 칸을 확정하려고 누른 클릭이 <b>이미 목록을 열어 놓는다.</b>
> 거기서 한 번 더 누르면 도로 닫혀 <c>목록에서 '쓰기' 를 찾지 못했습니다</c> 가 된다.
> 열려 있으면 누르지 않는다.

### 대화상자 안 그리드는 <b>상자 안에서</b> 찾아야 한다 ★

본문에도 같은 머리글의 그리드가 있다 — 영역명관리 상자와 성취기준 본문이 둘 다 "영역명" 열을 갖는다.
그냥 찾으면 <b>상자 뒤의 본문 그리드</b>를 잡는다. 행을 더해도 늘지 않아 한참 헤맸다.

### 그리드 열 번호는 <b>화면마다 다르다</b>

같은 값을 담은 열인데 자리가 다르다 — 영역명이 성취기준관리에서는 <b>2열</b>,
성취기준(평가기준)관리에서는 <b>1열</b>이다. <b>머리글로 찾는다.</b>

### 저장은 <b>바뀐 것이 있을 때만</b> 마지막 칸을 확정한다 ⚠

값이 예전과 똑같으면 나이스가 이렇게 거절한다:

```
알림  변경된 데이터가 없어서 저장할 수 없습니다.   [확인]
```

거절되면 <b>편집 중이던 마지막 칸이 확정되지 않아 빈 칸으로 보인다.</b>
저장된 값은 멀쩡하다 — <b>화면만</b> 그렇다. 재조회하면 원래대로 나온다(실측 2026-08-21).

> <b>교훈</b>: 대조는 <b>화면이 아니라 재조회한 뒤에</b> 한다.
> 넣은 직후의 화면은 아직 확정되지 않은 칸을 빈 칸으로 보여 준다.

## 6. 저장 — 시간표와 똑같이 두 단계다

```
[저장] → ① "저장하시겠습니까?"        [확인] [취소]
       → (빈 구간 — 서버 왕복)
       → ② "저장이 완료되었습니다."   [확인]      ← 이걸 눌러야 끝난다
```

`TimetableSaver` 에서 겪은 것과 <b>같은 구조</b>다(실기기검증 §4-Q).
①과 ② 사이에 아무 상자도 없는 구간이 있으므로, "상자가 사라졌다"를 성공으로 보면 안 된다.

바뀐 것이 없으면 `저장할 내역이 없습니다.` 가 뜬다 — 실패가 아니다.

### 작업 창도 <c>role=dialog</c> 다 ★★ (2026-08-22 실측)

일괄업로드 같은 <b>작업 창</b>과 "저장이 완료되었습니다" 같은 <b>알림</b>이 <b>둘 다</b> <c>[role=dialog]</c> 다.

"떠 있는 마지막 dialog" 를 알림으로 보면 <b>작업 창 자신을 알림으로 착각</b>한다 —
실제로 저장 확인을 못 누르고 <c>모르는 대화상자입니다: …기 등록된 영역명…</c> 으로 멈췄다.

<b>가리는 법</b>: 알림은 <b>안에 그리드가 없고</b> `확인`·`예` 단추를 가진 작은 상자다.
작업 창은 그리드를 갖고 있다. 그것으로 나눈다.

그리고 <b>누른 것과 닫힌 것은 다르다</b> — 확인을 누른 뒤 상자가 실제로 바뀌는 것을 보고 넘어간다.

## 7. 그 밖에 만난 상자

| 문구 | 언제 | 대응 |
|---|---|---|
| `변경사항이 반영되지 않았습니다. 계속 하시겠습니까?` | 편집 중에 조회 조건을 바꿀 때 | [확인]이면 버리고 진행 |
| `저장할 내역이 없습니다.` | 바뀐 것 없이 저장 | 정상 |

## 8. 실측으로 만든 한 건 (2026-08-21)

2026학년도 <b>2학기</b> 5학년 국어에 다음을 실제로 만들어 저장하고, 재조회로 확인했다.

```
영역명   문법                                    ← 영역명관리에 먼저 등록
성취기준 글과 담화에 쓰인 시간 표현을 이해하고 상황에 따라 활용하여 경험한 일을 글로 쓴다.
평가요소 시간 표현의 이해와 활용
단계     3단계
  잘함     글과 담화에 쓰인 다양한 시간 표현을 분석하고 … 쓸 수 있다.
  보통     글과 담화에 쓰인 시간 표현을 이해하고 … 쓸 수 있다.
  노력요함 글과 담화에 쓰인 시간 표현을 확인하고 … 쓸 수 있다.
```

- 평가기준 세 줄은 사용자가 알려 준 <b>1학기 국어 문법</b>의 실제 문구다.
- <b>성취기준·평가요소 두 줄은 그 문구에서 지어낸 임시값</b>이다 — 문서 파싱 전이라 진짜 값이 없었다.
- 같은 화면에 영역명 `1` `2` `3` 짜리 시험 행이 이미 하나 있었다(등록사용자 진두성). 우리가 만든 것이 아니다.

> 지우려면: 2단계에서 행을 고르고 [삭제] → 1단계에서 행을 고르고 [삭제] →
> [영역명관리]에서 `문법` 을 고르고 [삭제]. 각각 저장 확인이 따라온다.
