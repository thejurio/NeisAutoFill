# DooNeis — 나이스 자동입력

선생님이 이미 만들어 둔 문서(평가계획·연간 시간표)를 읽어, 나이스에 대신 입력해 주는 프로그램입니다.

## 내려받기

[**최신 버전 받기**](https://github.com/thejurio/NeisAutoFill/releases/latest) → `NeisAutoFill-win-Setup.exe`

설치형으로 설치하면 다음부터는 프로그램이 알아서 업데이트를 알려 줍니다.

## 하는 일

- **평가계획** — hwp·hwpx·pdf 문서를 읽어 나이스 평가계획(안)관리에 올립니다
- **교과평가** — 학생별 등급을 과목마다 넣고 저장합니다
- **교과학습** — 서술문을 만들고 다듬어 넣습니다
- **편제 및 시간배당** — 연간 시간표 문서 하나로 학교교육과정 편제를 맞춥니다
- **연간시간표 관리** — 주별 시간표를 학기 전체에 걸쳐 넣습니다

로그인과 메뉴 이동은 사용자가 직접 합니다. 프로그램은 로그인을 대신하지 않습니다.

## 사용법

프로그램 안의 **❓ → 자세한 사용법 보기**에 화면별 따라하기 설명서가 들어 있습니다.
