# DooNeis — 나이스 자동입력

선생님이 이미 만들어 둔 문서(평가계획·연간 시간표)를 읽어, 나이스에 대신 입력해 주는 프로그램입니다.

## 내려받기

[**최신 버전 받기**](https://github.com/thejurio/NeisAutoFill/releases/latest)

| 받을 것 | 어떤 경우에 | 자동 업데이트 |
|---|---|---|
| `NeisAutoFill-win-Setup.exe` | **보통 이걸 받으세요.** 설치하면 시작 메뉴에 등록됩니다 | **됩니다** — 새 버전이 나오면 프로그램이 알려 줍니다 |
| `NeisAutoFill-win-Portable.zip` | 설치가 막힌 PC, USB로 들고 다닐 때 | 안 됩니다 — 새 버전이 나오면 다시 받아야 합니다 |

포터블은 압축을 푼 뒤 폴더 안의 **`DooNeis.exe`** 를 실행하세요.
`current` 폴더 안의 파일을 직접 실행하거나 exe 하나만 따로 옮기면 나이스 연결이 되지 않습니다. **폴더째** 쓰세요.

> 설치할 때 파란 경고창("Windows의 PC 보호")이 뜨면 **추가 정보 → 실행**을 누르세요.
> 개인이 만든 프로그램이라 코드 서명이 없어서 뜨는 안내입니다.

## 하는 일

- **평가계획** — hwp·hwpx·pdf 문서를 읽어 나이스 평가계획(안)관리에 올립니다
- **교과평가** — 학생별 등급을 과목마다 넣고 저장합니다
- **교과학습** — 서술문을 만들고 다듬어 넣습니다
- **편제 및 시간배당** — 연간 시간표 문서 하나로 학교교육과정 편제를 맞춥니다
- **연간시간표 관리** — 주별 시간표를 학기 전체에 걸쳐 넣습니다

로그인과 메뉴 이동은 사용자가 직접 합니다. 프로그램은 로그인을 대신하지 않습니다.

## 처음 쓸 때

**작은 범위로 먼저 시험하세요.** 평가는 한 과목만, 시간표는 1주만 넣어 보고
나이스에서 다시 조회해 제대로 들어갔는지 확인한 뒤에 전체를 돌리세요.
나이스에 저장된 것은 프로그램이 되돌리지 못합니다.

프로그램 안의 **❓ → 자세한 사용법 보기** 에 화면별 따라하기 설명서가 들어 있습니다.
